Endpoints da API - Categoria

Abaixo estão os links para realizar operações CRUD na API de categorias da pizzaria:

  • GET - Listar Categirias: http://172.19.0.49/pizzariateste/api/v1/categorias
  • GET - Obter Categoria por ID: http://172.19.0.49/pizzariateste/api/v1/categorias/1
  • POST - Criar Categoria: http://172.19.0.49/pizzariateste/api/v1/categorias
  • PUT - Atualizar Categoria por ID: http://172.19.0.49/pizzariateste/api/v1/categorias/1
  • DELETE - Deletar Categoria por ID: http://172.19.0.49/pizzariateste/api/v1/categorias/1
  • PUT - Exclusão Lógica Categoria por ID: http://172.19.0.49/pizzariateste/api/v1/delete-logic/categorias/1

Observação: Os métodos POST, PUT e DELETE devem ser testados com ferramentas apropriadas, como Postman, Insomnia ou cURL, pois não podem ser executados diretamente através de um navegador.
